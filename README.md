# Ashish Chauhan — Personal Portfolio

A modern, responsive personal portfolio website built with **Next.js, TypeScript, SCSS, and React Icons**.

The website showcases my professional experience, technical skills, certifications, projects, and contact information with a clean and responsive user interface.

## Live Website

[ashishchauhan.tech](https://ashishchauhan.tech)

---

## Features

- Responsive design for desktop, tablet, and mobile
- Modern and clean user interface
- Component-based architecture
- Dedicated SCSS styling for each component
- Responsive navigation with active section highlighting
- Hero section
- About section
- Skills and technologies
- Professional experience
- Certifications
- Projects showcase
- Contact section
- Optimized images using Next.js Image
- Responsive mobile navigation
- Smooth scrolling

---

## Tech Stack

- **Next.js** — React framework
- **React** — User interface development
- **TypeScript** — Type-safe development
- **SCSS** — Component-level styling and responsive design
- **React Icons** — UI icons
- **Git** — Version control
- **GitHub** — Source code management
